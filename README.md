# Personal Inventory — public releases

Sideloadable **debug** APKs for friends testing **Personal Inventory**.

The app source lives in a private repo; this repo exists so anyone with the link can download the APK **without GitHub authentication**.

## PI V1.1 (beta)

**Direct download:**

https://github.com/sicpoe-wq/personal-inventory-releases/releases/download/v1.1/PI-V1.1.apk

Release page: https://github.com/sicpoe-wq/personal-inventory-releases/releases/tag/v1.1

### Install (Android)

1. Open the download link on your phone (or transfer the file).
2. Allow installs from that source (unknown apps / unknown sources).
3. Open the APK and install. It updates an earlier beta in place and keeps your data.
4. Launch **Personal Inventory**.

### Limits

- **Android only** (debug APK).
- Not Play Store–signed; phone must allow sideloading.
- Offline-first; optional internet for catalog search / covers / news.
- Data stays on the device (IndexedDB). No accounts.
